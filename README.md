# Event Management Web App

A responsive interactive event management page built with HTML, CSS, and JavaScript.

## Features

- View initial events from a predefined list
- Add new events dynamically with form validation
- Delete events from the list
- Search events by name or date
- Past events are styled differently from upcoming events
- Responsive layout for desktop, tablet, and mobile

## How to run

Open `index.html` in a browser or publish this repository with GitHub Pages.
